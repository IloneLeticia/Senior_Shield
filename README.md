## 📖 Sobre o projeto

O **Senior Shield** é uma aplicação web desenvolvida para **auxiliar e proteger pessoas idosas contra golpes e fraudes digitais**.

O projeto foi pensado a partir das dificuldades enfrentadas pelo público da terceira idade no ambiente digital, priorizando uma experiência simples, clara e acessível.

A interface utiliza **tipografia legível, contraste adequado, elementos visuais de fácil compreensão e navegação simplificada**, buscando reduzir barreiras de acesso à informação.

> 🛡️ **Nossa proposta:** transformar informação sobre segurança digital em uma experiência simples, acessível e prática.

---

## 🎯 Objetivo

O projeto busca conscientizar o público idoso sobre golpes virtuais e fornecer ferramentas que auxiliem na identificação e no enfrentamento dessas situações.

A aplicação reúne conteúdos educativos, recursos interativos e ferramentas de apoio em um único ambiente.

O projeto utiliza **JSON Server** para disponibilizar os dados armazenados em `src/dados.json` através de uma API REST local.

A configuração do projeto define o servidor para observar esse arquivo e disponibilizar a API durante a execução.

```text
src/dados.json
      │
      ▼
┌─────────────────┐
│   JSON Server   │
└────────┬────────┘
         │
         ▼
     REST API
         │
         ▼
┌─────────────────┐
│   JavaScript    │
│     Fetch       │
└────────┬────────┘
         │
         ▼
     Interface
```

## ♿ Acessibilidade

A acessibilidade é um dos pilares do projeto.

O desenvolvimento da interface considerou especialmente a experiência de usuários idosos, buscando tornar as informações mais fáceis de visualizar, compreender e utilizar.

* 🔠 Tipografia com foco em legibilidade;
* 📏 Tamanhos de fonte adequados;
* 🎨 Contraste entre elementos;

* 🖱️ Elementos interativos fáceis de identificar;
* 📖 Organização clara das informações;
* 📱 Adaptação para diferentes tamanhos de tela.

## 🚀 Como executar

### Pré-requisitos

É necessário ter instalado:

* [Node.js](https://nodejs.org/)
* npm
* Git

### 1. Clone o repositório

```bash
git clone https://github.com/IloneLeticia/Senior_Shield.git
```

### 2. Entre na pasta

```bash
cd Senior_Shield
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o servidor

```bash
npm start
```

O projeto utiliza o script configurado no `package.json` para iniciar o JSON Server utilizando `src/dados.json`.

### 5. Acesse a aplicação

Abra a página indicada pelo projeto no navegador ou utilize um servidor local para executar a interface.
