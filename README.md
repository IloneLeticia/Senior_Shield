Senior Shield 🛡️
O Senior Shield é uma plataforma desenvolvida para auxiliar e proteger a população idosa contra golpes e fraudes virtuais. O projeto prioriza a acessibilidade, utilizando tipografia, contraste e tamanhos de fonte cuidadosamente estudados para a melhor experiência visual da terceira idade.


🚀 Funcionalidades
 * Golpe Tube: Conteúdo em vídeo explicativo sobre fraudes comuns.
 * Acordeão Informativo: Seção interativa com explicações detalhadas sobre diferentes tipos de golpes.
 * Gráfico de Golpes: Visualização de dados sobre a frequência e tipos de golpes.
 * Área de Comentários: Espaço para interação e troca de experiências entre usuários.
 * Relato de Golpes: Formulário simplificado para reportar tentativas ou golpes sofridos.
 * Checklist Anti-Golpe: Ferramenta interativa que calcula a probabilidade de o usuário estar sendo vítima de uma fraude.
 * Gerador de Boletim de Ocorrência: Auxiliar para criação e encaminhamento de B.O.
🎨 Acessibilidade & Design
O design do projeto foi desenvolvido coletivamente, focando na usabilidade para o público sênior:
 * Fontes e tamanhos adaptados para alta legibilidade.
 * Paleta de cores com alto contraste.
 * Interface simples e intuitiva.
